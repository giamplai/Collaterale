# Code of Conduct

We want Collaterale to be a welcoming project for everyone, regardless of experience, background or identity.

**Expected:** be respectful and constructive, assume good faith, accept feedback gracefully, focus on what is best for the project.

**Not acceptable:** harassment, insults, discrimination, personal attacks, publishing others' private information, or other conduct a reasonable person would find inappropriate in a professional setting.

Maintainers may remove comments, issues or contributions that violate this code and may ban repeat offenders.
Report problems privately to the maintainer, Giampiero Lai, at giampiero.lai@gmail.com.

This policy is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
